# makingbaby

Starter monorepo combining a simple backend and frontend for the MakingBaby MVP.

## Development

Install dependencies:

```
npm install
```

Build both apps:

```
npm run build
```

Run backend:

```
npm run dev -w backend
```

Run frontend:

```
npm run dev -w frontend
```

## Testing

Run all tests:

```
npm test
```

Run backend tests:

```
npm test -w backend
```

Run frontend tests:

```
npm test -w frontend
```
